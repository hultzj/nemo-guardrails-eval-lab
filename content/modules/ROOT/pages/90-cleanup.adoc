:navtitle: Cleanup

== Remove what you created

You created a `NemoGuardrails` resource, three rail ConfigMaps, and evaluation Jobs. Look at
them first, then delete them. The live monitor, the dataset and your namespace belong to the
lab and stay.

[source,bash,role="execute",subs="attributes+"]
----
NS=$(oc whoami){tenant_suffix}
oc -n $NS get nemoguardrails,jobs -o name
oc -n $NS get configmap regex-only content-safety tuned -o name
----

Expected result: `nemoguardrails.trustyai.opendatahub.io/nemoguardrails`, one `job.batch/eval-...`
per evaluation you ran, and `configmap/regex-only`, `configmap/content-safety`, `configmap/tuned`.

[CAUTION]
====
The next block deletes them. Your Web Terminal keeps running: it lives in a DevWorkspace in
this namespace, which is not deleted.
====

[source,bash,role="execute"]
----
oc -n $NS delete nemoguardrails nemoguardrails --ignore-not-found --wait=true
oc -n $NS delete jobs -l app=guardrails-eval --ignore-not-found
oc -n $NS delete configmap regex-only content-safety tuned --ignore-not-found
oc -n $NS get deploy,route -o name
----

Expected result: every deletion reports `deleted from <you>{tenant_suffix} namespace`, and the
last command lists only `deployment.apps/rails-monitor`, your terminal's
`deployment.apps/workspace...`, and `route.route.openshift.io/rails-monitor`: the operator
removed the guardrails Deployment, Service and Route with the resource.

== Remove the lab environment (whoever deployed it)

Only the person who ran the bootstrap removes the environment. From a cluster-admin shell in
a checkout of this repository, first look at what the teardown will delete. Every Application
listed goes, along with everything it created, including every `*{tenant_suffix}` namespace:

[source,bash,subs="attributes+"]
----
make -C automation status
oc get namespace -l app.kubernetes.io/part-of=nemo-guardrails-eval-lab
----

Then delete it and confirm the namespaces are gone:

[source,bash,subs="attributes+"]
----
make -C automation teardown
oc get namespace -l app.kubernetes.io/part-of=nemo-guardrails-eval-lab
----

The last command prints `No resources found` once deletion completes. Two things outlive the
teardown, by design or because they were created outside Argo CD:

* The Keycloak users from `make users`. Remove them in the Keycloak admin console if they are no longer needed.
* The DevWorkspace operator, which the Web Terminal operator pulled in. Look before removing:
  `oc get csv -n openshift-operators | grep -E 'web-terminal|devworkspace'`.
