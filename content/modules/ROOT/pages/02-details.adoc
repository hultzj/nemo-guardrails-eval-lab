= Prerequisites and Environment
:navtitle: Prerequisites and Environment

== What you need

|===
| If you are… | You need

| Every participant
| A username and password from the facilitator and a browser. The *OpenShift Console* tab opens the console in a new browser tab.
Commands run in the console's Web Terminal (or your own `oc` and `jq`, logged in as yourself).

| A presenter
| The same, plus a second browser window for the live monitor so the audience sees decisions arrive.
|===

Provided by the facilitator:

* An OpenShift {ocp_version} cluster with OpenShift AI {rhoai_version} (TrustyAI component enabled) and this lab deployed through OpenShift GitOps.
* Your own namespace, `<your username>{tenant_suffix}`, with the live monitor already running in it.
* The shared safety model in `{lab_namespace}`.

You act as *your own OpenShift user* throughout. In your namespace you can read everything
except Secrets, and you can create ConfigMaps, `NemoGuardrails` resources and Jobs, and open a terminal (exec) into pods. Nothing else.

== Open a terminal

. Click the *OpenShift Console* tab (it opens a new browser tab) and log in with *keycloak* and your username and password.
. Click the terminal icon (*>_*) in the console masthead.
. If asked for a project, choose `<your username>{tenant_suffix}` and click *Start*.

Expected result: a terminal opens at the bottom of the console with a shell prompt.

== Run the pre-flight check

Run this in the Web Terminal. The first line names your namespace; re-run it whenever the
terminal restarts.

[source,bash,role="execute",subs="attributes+"]
----
NS=$(oc whoami){tenant_suffix}
oc whoami
oc get namespace $NS
for r in nemoguardrails.trustyai.opendatahub.io configmaps jobs.batch; do
  echo "create $r: $(oc auth can-i create $r -n $NS)"
done
echo "get pods/log: $(oc auth can-i get pods --subresource=log -n $NS)"
echo "get secrets: $(oc auth can-i get secrets -n $NS)"
jq --version
----

Expected result: `oc whoami` prints your username, the namespace is `Active`, the three
`create` lines and `get pods/log` print `yes`, `get secrets` prints `no`, and `jq` prints a version.
The `no` is the point: the lab grants exactly what the exercises need.
// UNVERIFIED
