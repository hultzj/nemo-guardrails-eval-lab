== Run the pre-flight check

Run these in the Showroom terminal:

[source,bash,role="execute",subs="attributes+"]
----
oc whoami
oc get namespace {lab_namespace}
oc auth can-i CHANGE-ME -n {lab_namespace}
----

Expected result: `oc whoami` prints
`system:serviceaccount:{showroom_namespace}:showroom`, the namespace is
`Active`, and every `auth can-i` line prints `yes`.
